# 💰 Personal Finance AI Advisor

A Python-based personal finance management and analytics application built using Streamlit and SQLite.

## Features

- Income tracking
- Expense tracking
- Category-wise expenses
- Budget management
- Financial dashboard
- Interactive analytics
- CSV export
- Smart financial insights
- Machine-learning based expense prediction
- SQLite database

## Technologies

- Python
- Streamlit
- SQLite
- Pandas
- Plotly
- Scikit-learn
